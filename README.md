# Car Lane Dash

A lightweight browser car game built with plain HTML, CSS, and JavaScript.

## How to play

- Click **Start Game**.
- Move left/right using **Arrow keys** or **A/D**.
- Avoid incoming traffic.
- Score increases as long as you survive.
- High score is saved in browser local storage.

## Cheat code

- Type `MARIO3DLAND` while a run is active.
- Cheat mode grants temporary invincibility and faster score gain for 10 seconds.

## Run locally

Open `index.html` in your browser.
